# Security policy

## Supported versions

Only the newest published release is considered for security fixes. During
the alpha phase, releases are exact-version experiments and are not a
production recommendation.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting form:

https://github.com/jan-guenter/bluemap-framedblocks-addon/security/advisories/new

Do not disclose a suspected vulnerability in a public issue before a fix or
coordinated disclosure is ready. Include the affected add-on version, exact
BlueMap and FramedBlocks versions, a concise reproduction, expected impact,
and any logs with credentials, addresses, world data, and player information
removed.

Ordinary rendering defects and compatibility requests may use the public
issue tracker.
